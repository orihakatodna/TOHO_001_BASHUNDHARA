# TOHO_001_BASHUNDHARA

Bashundhara 案件（2609）の住戸1戸分の3Dモデル（概念モデル・施工用ではない）。

- `models/unit_brick.html` — レンガ造（イングリッシュボンド）、3寝室の家具配置・床仕上げ切替
- `models/unit_concrete.html` — コンクリート打ち放し（型枠 1,800 × 900、Pコン @600 × @450）

HTML をブラウザーで開くだけで動く（インターネット接続が必要。three.js を cdnjs から読む）。

検図: `python tools/check_model.py`
